## About

I build software that has to keep working after launch day. Most of my seven years have gone into the parts nobody screenshots: the multi-tenant data model that survives the next pricing change, the event-driven service that doesn't drop messages under load, the API contract that lets separate teams ship without a meeting. I own features from architecture through to production monitoring, and I lead the engineers doing the same.

I got here sideways — Business Administration at the University of Lagos, freelance web work from 2016, a development traineeship in 2019, junior Angular dashboards for financial auditors, then full-stack at Exquis App Factory in 2021, promoted twice over five years while co-founding a streaming platform on the side.

The work I care about now is **building AI systems, not just applying them**. The MCP (Model Context Protocol) server behind my portfolio is one — designed, built, and shipped to AWS Lambda so AI assistants like Claude and ChatGPT query my real projects, work history, and capabilities through typed tools instead of scraping a page. The same discipline carries into the model features I build inside other products: typed interfaces, real monitoring, and a review bar that AI-assisted code has to clear like any other.

## 🤖 Talk to my portfolio, don't just read it

My portfolio runs on its own **MCP (Model Context Protocol) server** — designed, built, and deployed to AWS Lambda. Point any MCP-capable AI assistant at it and it can read my real projects, work history, capabilities, and published packages directly, instead of scraping a page built for people.

```
Endpoint:  https://mcp.okekecornelius.com
Stack:     NestJS · TypeScript · AWS Lambda · API Gateway · AWS CDK · CloudWatch
Tools:     get_profile · get_about · get_experience · get_projects
           get_skills · get_packages · get_contact · get_mcp_server
```
