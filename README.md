## About

I build software that has to keep working after launch day. Most of my seven years went into the parts nobody screenshots: a data model that survives the next pricing change, a service that doesn't drop messages under load, an API contract that lets two teams ship without a meeting. I own features from the architecture to the monitoring in production, and I lead the engineers who do the same.

I got here sideways. I studied Business Administration at the University of Lagos and built websites for small businesses on Upwork and Fiverr from 2016. In 2019 I did a development traineeship, then started as a junior frontend developer building Angular dashboards for financial auditors. I joined Exquis as a full-stack developer in 2021 and was promoted twice in the next five years, first to senior and then to lead. Alongside that, I co-founded a streaming platform.

What I care about now is building AI systems, not just using them. The MCP server behind my portfolio is one: I designed it, built it, and shipped it to AWS Lambda, so AI assistants can read my real data through typed tools instead of scraping a web page. I bring the same habits to the model features I build inside other products: typed interfaces, real monitoring, and code review that AI-written code has to pass like anyone else's.

## 🤖 Talk to my portfolio, don't just read it

My portfolio runs on its own MCP (Model Context Protocol) server. I designed it, built it, and deployed it to AWS Lambda. Claude, ChatGPT, and other AI assistants can call its typed tools to read my real projects, work history, skills, and published packages directly, instead of scraping a page written for people.

```
Endpoint:  https://mcp.okekecornelius.com
Stack:     NestJS · TypeScript · AWS Lambda · API Gateway · AWS CDK
           AWS CloudFormation · AWS IAM · CloudWatch
Tools:     get_profile · get_about · get_experience · get_projects
           get_skills · get_packages · get_contact · get_mcp_server
```
